# WHO U NAME?

### Remember the Face. Guess the Name.

WHO U NAME? is a casual memory game designed to challenge your ability to remember faces and names through interactive gameplay, timed challenges, and progressive difficulty.

## About the Game

Test your memory, improve your recognition skills, and challenge yourself through different game modes.

## Game Modes

- **Word Scramble** — Reconstruct character names using shuffled letters.
- **Face & Name Memory** — Memorize character faces and match them with their correct names.
- **Endless Mode** — Keep playing as difficulty increases.
- **Tournament Mode** — Compete using memory accuracy and scoring, if available in the current release.
- **Daily Challenge** — Complete daily memory challenges, if available.

## Features

- Character-based memory challenges.
- Progressive levels and difficulty.
- Score and XP progression.
- Player profiles and statistics.
- Achievement and streak systems.
- Responsive interface for mobile, tablet, and desktop.

## Technology Stack

- React
- Vite
- JavaScript
- Tailwind CSS

## Getting Started

Clone the repository:
```bash
git clone https://github.com/firdausmahfooza-cpu/who-u-name.git
```

Navigate to the project directory:
```
cd who-u-name
```

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
